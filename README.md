## Abstract

The spread of Coronavirus started at the end of the year 2019 from Wuhan, China. The continuous spread of the virus forced governments of various countries to put lockdowns for several months. It has been observed that wearing a face mask can prevent the transmission of this deadly virus. In the future, we have to use face masks as a preventive measure for any such viruses. However, manually it is very difficult to keep track of a person wearing a mask or not.

This project highlights the importance of deep learning, especially object detection. We introduce a deep learning model that detects faces and predicts whether the person is wearing a mask or not.

## Features

- Real-time face detection using Haar Cascade classifier
- Mask/no-mask classification using a CNN model
- Works with webcam feed and static images
- Simple and easy to use

## Tech Stack

- **Language** - Python
- **Libraries** - TensorFlow/Keras, OpenCV, NumPy, Pillow
- **Detection** - Haar Cascade Classifier
- **Classification** - Convolutional Neural Network (CNN)

## How to Run

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the Python script: `python face_mask_detection_in_code_.py`
4. Or open the Jupyter Notebook: `Face_Mask_detection_in_Code_.ipynb`
